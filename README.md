# Multivias Louvor

Player de multitracks para o louvor da Igreja Metodista Rita Vieira, feito para rodar no iPad como app de tela inicial (PWA).

- Faixas separadas com mesa de faders, grupos, Split L/R (fone/PA) e estéreo opcional
- Seções, arranjo personalizado, loop, saltos e mapa da música com forma de onda
- Modo palco, contagem de entrada, click e pad no tom da música
- Mudança de tom e andamento (SoundTouchJS, LGPL-2.1, carregado do jsDelivr)
- Cifra que transpõe junto com o tom
- Backup .multivias (setlist com áudio ou só seções e cifras)

As músicas ficam guardadas só no aparelho (IndexedDB). Nada é enviado para servidor.

Site estático: basta publicar esta pasta (Vercel, Netlify ou qualquer hospedagem). Para instalar no iPad, abra o link no Safari e use Compartilhar > Adicionar à Tela de Início.
